# AI Project Manager

AI ve yazılım projelerinin fikir aşamasından geliştirme sürecine kadar **detaylarını düzenli bir şekilde tutmak ve ilerlemelerini takip etmek** amacıyla geliştirilmiş bir proje yönetim uygulamasıdır.

## 🎯 Amaç

Proje fikirlerini, hedeflerini, detaylarını ve geliştirme sürecini tek bir yerde toplamak ve projelerin takibini kolaylaştırmak.
