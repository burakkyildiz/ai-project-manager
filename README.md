# AI Project Manager

A project management app built to **keep the details of AI and software projects organized and track their progress**, from the idea stage through development.

## 🎯 Purpose

Keep project ideas, goals, details and development progress in one place, and make it easier to follow every project.

## ✨ Features

- 📁 Project management on a single screen
- 🔎 Search by project name and description
- 🏷️ Filter by status, category and priority
- ➕ Add projects
- ✏️ Edit projects
- 🗑️ Delete projects with confirmation
- 💾 Data stored in the browser with LocalStorage
- 📱 Responsive design
- 🎨 Minimal dark interface

## 🛠️ Tech Stack

React 19, Vite 8, Tailwind CSS 4, JavaScript (JSX)

## 🚀 Getting Started

```bash
npm install
npm run dev
```
